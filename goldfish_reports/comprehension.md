# UX and Ergonomics-Brainstormer report

No blocker for continued brainstorming. Unresolved product contracts:

1. **Major — live changes.** Component changes and automation lack a distinction between continuous controls and circuit reconstruction. Define automation support, audible transitions, immediate versus apply behavior, bounded processing and predictable transitions.
2. **Major — initial workflow.** No path from load to stock sound is stated. Describe loading a stock model, adjusting Drive/Tone/Volume, customization and restoring stock. Decide whether model changes preserve knobs and reset modifications.
3. **Major — session recall.** Seeds, revisions, substitutions and quality settings can reconstruct different sound. Save the complete audible configuration, explicit component values and device models; define unsupported-state behavior.
4. **Major — oversampling choice.** 4x/8x may be experiments, user choices or automatic modes. Decide ownership; if exposed, define labels, switching, persisted state and latency updates.
5. **Major — failure UX.** Nonconvergence recovery lacks audible semantics. Specify bounded fallback/recovery, nonintrusive status and actionable repeated-failure behavior.
6. **Major — host/input contract.** Channel layouts, bypass, defaults and digital-level-to-voltage conversion are missing. Define mono/stereo behavior, bypass semantics, initial controls and guitarist-facing calibration.
